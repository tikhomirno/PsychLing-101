# Contributing

Before working with any dataset, please contact us by creating an
[issue](https://github.com/Data-X01/PsychLing-101/issues/new/choose) or sending us an
[email](mailto:psychling101@gmail.com).

**one submitted folder = one study**. The contributor is the author of the pull request
